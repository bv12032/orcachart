# オルカチャート

保険・ライフプラン・家計簿を1つにまとめた、スマホでもパソコンでも使えるWebアプリです。

- 開く：https://bv12032.github.io/orcachart/
- iPhone：Safariで開いて「共有」→「ホーム画面に追加」
- Android：Chromeで開いて「︙」→「ホーム画面に追加」

入力した内容は、使っている端末のブラウザの中だけに保存されます（このページの置き場所には送られません）。ときどき各画面の「CSVに書き出す」で控えを残してください。

税金・社会保険・年金・教育費の計算は、2025〜2026年度の制度と公的な統計をもとにした概算です。

グラフの部品に Chart.js（MITライセンス、chart.js-LICENSE.md）を使っています。
